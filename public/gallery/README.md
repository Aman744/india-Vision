# India Vision Showroom Gallery Photos

Drop your real showroom photos here and update `src/data/gallery.js` accordingly.

## Expected File Names
| File Name        | Gallery Card                        |
|------------------|-------------------------------------|
| storefront.jpg   | India Vision Showroom — Rishikesh  |
| tv-wall.jpg      | Smart TV Display Wall               |
| appliances.jpg   | Home Appliances Section             |
| team.jpg         | Our Expert Sales Team               |
| ac-zone.jpg      | Air Conditioner Zone                |
| billing.jpg      | Smooth Billing & Checkout           |

## How to Add Photos
1. Copy your photo files here (e.g. from Google Maps Photos tab)
2. Open `src/data/gallery.js`
3. Replace each `image:` URL with `/gallery/<filename>` (e.g. `"/gallery/storefront.jpg"`)

## Getting Photos from Google Maps
1. Open: https://www.google.com/maps/place/India+Vision+Electronics/
2. Click "Photos" tab
3. Right-click each photo → Save image as
4. Save to this folder with the names above
